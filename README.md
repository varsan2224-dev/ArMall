# ArMall — React E-commerce Website

ArMall is a responsive e-commerce website built with React and Tailwind CSS.

## Live Demo

https://armall.vercel.app

## Features

- Responsive design for desktop and mobile
- Product listing page
- Product details page
- Shopping cart functionality
- Cart persistence with localStorage
- Authentication modal UI
- Mobile burger menu
- React Router navigation
- Reusable components and custom hooks

## Tech Stack

- React
- JavaScript
- Tailwind CSS
- React Router
- Vite
- Framer Motion
- React Icons

## Project Purpose

This is a personal portfolio project created to demonstrate frontend development skills for modern e-commerce interfaces.
